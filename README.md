# FORGE : Librairy of Machine Learning in RUST

## Introduction
A lightweighted librairy of machine learning written in rust.

The goal is to implement common machine Learning models algorithms from scratch while exploring the rust's performance.

## Why rust ?
This project is also an exploration of Rust for numerical and Machine Learning workloads.

Rust provides: 
- memory safety without garbage collector
- predictable performance
- zero-cost abastractions
- native compilation
- explicit control over memory and concurrency

The objective is to determine where these properties provide practical advantages for machine learning workloads.
